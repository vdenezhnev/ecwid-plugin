## Общие вопросы

### Что делает этот плагин?

Плагин синхронизирует заказы из вашего магазина Ecwid в WooCommerce. Это позволяет управлять всеми заказами в одном месте, используя мощные инструменты WooCommerce для аналитики, отчётов и выполнения заказов.

### Синхронизируются ли товары?

Текущая версия синхронизирует только заказы. Синхронизация товаров планируется в будущих версиях.

### Можно ли использовать плагин без WooCommerce?

Нет, плагин требует активной установки WooCommerce. Он создаёт заказы в формате WooCommerce и использует его API.

### Плагин бесплатный?

Да, плагин распространяется под лицензией GPL v2 и полностью бесплатен.

### Какие версии WordPress поддерживаются?

- WordPress 5.8 и выше
- PHP 7.4 и выше
- WooCommerce 5.0 и выше

## Установка и настройка

### Где найти Store ID и API Token?

1. Войдите в [панель управления Ecwid](https://my.ecwid.com)
2. Перейдите в **Настройки** → **API** (или **Apps** → **API**)
3. Store ID отображается в верхней части страницы
4. Создайте API токен или используйте существующий

### Какие разрешения нужны для API токена?

Минимально необходимые разрешения:
- `read_orders` — чтение заказов
- `read_customers` — чтение информации о клиентах
- `update_orders` — обновление статусов заказов (для двусторонней синхронизации)

### Как проверить, что плагин настроен правильно?

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Sync**
2. Нажмите кнопку **Test Connection**
3. Если появляется зелёное сообщение "Connection successful!" — всё настроено правильно

### Нужен ли SSL-сертификат (HTTPS)?

SSL настоятельно рекомендуется, особенно для работы вебхуков. Ecwid может не отправлять вебхуки на HTTP-адреса.

## Синхронизация заказов

### Как часто синхронизируются заказы?

Есть два механизма:

1. **Вебхуки** — мгновенно при создании/изменении заказа в Ecwid
2. **WP-Cron** — по расписанию (от 5 минут до 1 раза в день)

### Почему заказ не появился в WooCommerce?

Возможные причины:
- Заказ ещё не был синхронизирован (проверьте время последней синхронизации)
- Ошибка API (проверьте логи)
- Заказ уже существует (плагин не создаёт дубликаты)

### Как запустить синхронизацию вручную?

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Sync**
2. Нажмите **Sync Now**

### Как синхронизировать старые заказы?

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Sync**
2. Выберите дату в поле **From Date**
3. Нажмите **Run Full Sync**

### Что происходит с уже существующими заказами?

Плагин отслеживает связь между Ecwid и WooCommerce заказами. При повторной синхронизации:
- Новые заказы — создаются
- Существующие заказы — обновляются (статус, данные)
- Дубликаты не создаются

### Синхронизируются ли изменения из WooCommerce в Ecwid?

Да, при изменении статуса заказа в WooCommerce, статус автоматически обновляется в Ecwid.

## Вебхуки

### Что такое вебхуки и зачем они нужны?

Вебхуки — это уведомления от Ecwid, которые отправляются мгновенно при создании или изменении заказа. Без вебхуков заказы синхронизируются только по расписанию WP-Cron.

### Как настроить вебхуки?

**Автоматически:**
1. Перейдите в настройки плагина
2. Нажмите **Register Webhook Automatically**

**Вручную:**
1. Скопируйте URL из настроек плагина
2. Добавьте его в Ecwid → Settings → API → Webhooks

### Вебхуки не работают. Что делать?

1. Проверьте, что сайт доступен по HTTPS
2. Убедитесь, что URL вебхука возвращает код 200
3. Проверьте файрволл — он может блокировать POST-запросы
4. Проверьте, что опция **Enable Webhooks** включена
5. Проверьте логи на наличие ошибок подписи

### Можно ли использовать плагин без вебхуков?

Да, плагин будет работать через WP-Cron, но синхронизация будет происходить с задержкой (в зависимости от выбранного интервала).

## Клиенты и платежи

### Создаются ли клиенты автоматически?

Да, если включена опция **Create Customers**. При импорте заказа:
1. Плагин ищет клиента по email
2. Если найден — связывает заказ с ним
3. Если не найден — создаёт нового

### Как отключить создание клиентов?

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Settings**
2. Снимите галочку **Create Customers**
3. Сохраните настройки

### Как маппятся платёжные методы?

Плагин автоматически определяет платёжный метод по названию в Ecwid:
- PayPal → PayPal
- Stripe → Credit Card (Stripe)
- Cash → Cash on Delivery
- Bank Transfer → BACS

Для неизвестных методов используется "Other".

### Можно ли настроить свой маппинг платежей?

Да, через PHP-фильтр:

```php
add_filter( 'ecwid_payment_method_mappings', function( $mappings ) {
    $mappings['МойПлатёж'] = array(
        'id'    => 'my_payment',
        'title' => 'Мой способ оплаты',
    );
    return $mappings;
});
```

## Производительность

### Влияет ли плагин на скорость сайта?

Минимально. Основная работа происходит в фоне через WP-Cron или при обработке вебхуков.

### Какой интервал синхронизации лучше выбрать?

- **5-15 минут** — для активных магазинов с большим потоком заказов
- **30-60 минут** — оптимальный баланс для большинства магазинов
- **Дважды в день / Ежедневно** — для небольших магазинов

### Сколько заказов может обработать плагин?

Плагин обрабатывает заказы пакетами по 100 штук. Полная синхронизация большого магазина (10000+ заказов) может занять несколько минут.

### WP-Cron не работает. Что делать?

Если на вашем хостинге WP-Cron работает нестабильно:

1. Настройте системный cron:
   ```bash
   */5 * * * * wget -q -O - https://ваш-сайт.ru/wp-cron.php?doing_wp_cron >/dev/null 2>&1
   ```

2. Или добавьте в `wp-config.php`:
   ```php
   define( 'DISABLE_WP_CRON', true );
   ```

## Ошибки и решения

### "API not configured"

**Причина:** Не заданы Store ID или API Token.

**Решение:**
1. Перейдите в настройки плагина
2. Введите Store ID и API Token
3. Сохраните настройки

### "Connection failed"

**Причина:** Неверные учётные данные или проблемы с сетью.

**Решение:**
1. Проверьте правильность Store ID и API Token
2. Убедитесь, что токен активен в Ecwid
3. Проверьте, что хостинг не блокирует исходящие запросы

### "Invalid webhook signature"

**Причина:** Подпись вебхука не совпадает.

**Решение:**
1. Удалите вебхук в Ecwid
2. Зарегистрируйте заново через плагин
3. Или отключите проверку подписи в режиме отладки

### "Order not found"

**Причина:** Заказ был удалён в Ecwid или неверный ID.

**Решение:** Проверьте, существует ли заказ в панели Ecwid.

### Ошибки в логах при создании клиента

**Причина:** Email клиента уже существует или некорректен.

**Решение:**
1. Проверьте данные заказа в Ecwid
2. Убедитесь, что email не пустой
3. Проверьте, нет ли дубликата клиента в WooCommerce

### Заказы создаются, но без товаров

**Причина:** Товары в Ecwid не имеют SKU, совпадающего с товарами WooCommerce.

**Решение:** Товары добавляются как произвольные позиции. Для полного соответствия синхронизируйте каталог товаров отдельно.

## Не нашли ответ?

1. Проверьте [Руководство пользователя](USER_GUIDE.md)
2. Изучите логи плагина (**WooCommerce** → **Ecwid Sync** → **Logs**)
3. Включите режим отладки WordPress для получения детальной информации
4. Создайте issue в репозитории проекта с описанием проблемы и логами
