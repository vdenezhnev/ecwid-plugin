## Введение

**Ecwid WooCommerce Sync** — это WordPress плагин, который позволяет автоматически синхронизировать заказы из вашего магазина Ecwid в WooCommerce. Плагин поддерживает:

- Импорт новых заказов в режиме реального времени через вебхуки
- Периодическую синхронизацию через WP-Cron
- Двустороннюю синхронизацию статусов заказов
- Автоматическое создание клиентов в WooCommerce
- Маппинг платёжных методов

## Требования

Для работы плагина необходимы:

- WordPress 5.8 или выше
- PHP 7.4 или выше
- WooCommerce 5.0 или выше
- Активный магазин Ecwid с API-доступом
- SSL-сертификат (HTTPS) для работы вебхуков

## Установка

### Метод 1: Ручная установка

1. Скачайте архив плагина
2. Перейдите в админ-панель WordPress → **Плагины** → **Добавить новый**
3. Нажмите **Загрузить плагин** и выберите скачанный архив
4. Нажмите **Установить** и затем **Активировать**

### Метод 2: Через FTP

1. Распакуйте архив плагина
2. Загрузите папку `ecwid-woocommerce-sync` в директорию `/wp-content/plugins/`
3. Активируйте плагин через меню **Плагины** в WordPress

## Настройка

### Получение API-ключей Ecwid

1. Войдите в панель управления Ecwid: https://my.ecwid.com
2. Перейдите в **Настройки** → **API**
3. Создайте новое приложение или используйте существующее
4. Скопируйте **Store ID** и **API Token**

> **Важно:** Убедитесь, что токен имеет права на чтение заказов и клиентов.

### Настройка плагина

1. В админ-панели WordPress перейдите в **WooCommerce** → **Ecwid Sync**
2. На вкладке **Settings** введите:
   - **Store ID** — числовой идентификатор вашего магазина Ecwid
   - **API Token** — секретный ключ API
3. Нажмите **Сохранить изменения**
4. Нажмите **Test Connection** для проверки подключения

### Интервал синхронизации

Выберите, как часто плагин будет проверять новые заказы:

| Интервал | Описание |
|----------|----------|
| Каждые 5 минут | Для активных магазинов с большим потоком заказов |
| Каждые 15 минут | Рекомендуется для средних магазинов |
| Каждые 30 минут | Оптимальный баланс производительности |
| Каждый час | По умолчанию |
| Дважды в день | Для небольших магазинов |
| Ежедневно | Минимальная нагрузка на сервер |

### Настройка вебхуков

Вебхуки позволяют получать уведомления о заказах мгновенно, без ожидания очередной синхронизации.

#### Автоматическая регистрация

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Settings**
2. Найдите секцию **Webhook URL**
3. Нажмите **Register Webhook Automatically**

#### Ручная регистрация

Если автоматическая регистрация не сработала:

1. Скопируйте URL из настроек плагина:
   ```
   https://ваш-сайт.ru/wp-json/ecwid-sync/v1/webhook
   ```
2. В панели Ecwid перейдите в **Настройки** → **API** → **Webhooks**
3. Добавьте новый вебхук с указанным URL
4. Выберите события:
   - `order.created`
   - `order.updated`
   - `order.deleted`

## Использование

### Автоматическая синхронизация

После настройки плагин будет автоматически:

1. Получать новые заказы через вебхуки (мгновенно)
2. Проверять обновления по расписанию WP-Cron
3. Синхронизировать статусы заказов между платформами

### Ручная синхронизация

Для запуска синхронизации вручную:

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Sync**
2. Нажмите **Sync Now** для обычной синхронизации
3. Или выберите дату и нажмите **Run Full Sync** для полной синхронизации

### Просмотр синхронизированных заказов

Синхронизированные заказы отображаются в стандартном списке заказов WooCommerce. Для просмотра информации об Ecwid:

1. Откройте любой заказ
2. Найдите блок **Ecwid Order Info** на боковой панели

В этом блоке отображается:
- Ecwid Order ID
- Номер заказа в Ecwid
- Статус оплаты
- Статус выполнения
- Время последней синхронизации

## Маппинг данных

### Статусы заказов

#### Ecwid → WooCommerce

| Ecwid Payment | Ecwid Fulfillment | WooCommerce |
|--------------|-------------------|-------------|
| PAID | AWAITING_PROCESSING | Processing |
| PAID | PROCESSING | Processing |
| PAID | SHIPPED | Completed |
| PAID | DELIVERED | Completed |
| AWAITING_PAYMENT | любой | Pending |
| CANCELLED | любой | Cancelled |
| REFUNDED | любой | Refunded |

#### WooCommerce → Ecwid

| WooCommerce | Ecwid Fulfillment |
|-------------|-------------------|
| Pending | AWAITING_PROCESSING |
| Processing | PROCESSING |
| Completed | SHIPPED |
| Cancelled | WILL_NOT_DELIVER |
| Refunded | RETURNED |

### Платёжные методы

Плагин автоматически определяет платёжный метод:

| Ecwid | WooCommerce |
|-------|-------------|
| PayPal | PayPal |
| Stripe | Credit Card (Stripe) |
| Cash / CashOnDelivery | Cash on Delivery |
| BankTransfer / WireTransfer | Bank Transfer (BACS) |
| Square | Square |
| Klarna | Klarna |
| AfterPay | AfterPay |

### Клиенты

При импорте заказа плагин:

1. Ищет существующего клиента по email
2. Если найден — связывает заказ с ним
3. Если не найден и включена опция **Create Customers** — создаёт нового клиента

Данные клиента синхронизируются:
- Имя и фамилия
- Email и телефон
- Адрес доставки
- Адрес для счёта

## Логирование

Все операции синхронизации записываются в логи.

### Просмотр логов

1. Перейдите в **WooCommerce** → **Ecwid Sync** → **Logs**
2. Логи отображаются с указанием:
   - Даты и времени
   - Уровня (DEBUG, INFO, WARNING, ERROR)
   - Сообщения
   - Контекста (дополнительные данные)

### Уровни логирования

- **DEBUG** — детальная отладочная информация (только в режиме WP_DEBUG)
- **INFO** — стандартные операции (импорт, обновление)
- **WARNING** — предупреждения (пропущенные заказы)
- **ERROR** — ошибки (неудачные операции)

### Очистка логов

- Логи автоматически очищаются через 30 дней
- Для немедленной очистки нажмите **Clear Logs**

## Устранение неполадок

### Проблема: Заказы не синхронизируются

1. Проверьте подключение: **Test Connection**
2. Убедитесь, что **Enable Sync** включён
3. Проверьте логи на наличие ошибок
4. Убедитесь, что WP-Cron работает

### Проблема: Вебхуки не работают

1. Проверьте, что сайт доступен по HTTPS
2. Убедитесь, что вебхук зарегистрирован в Ecwid
3. Проверьте **Enable Webhooks** в настройках
4. Проверьте файрволл на блокировку POST-запросов

### Проблема: Ошибка "API not configured"

1. Перейдите в настройки плагина
2. Введите правильные Store ID и API Token
3. Сохраните настройки

### Проблема: Клиенты не создаются

1. Проверьте опцию **Create Customers** в настройках
2. Убедитесь, что заказ содержит email клиента

### Включение отладочного режима

Добавьте в `wp-config.php`:

```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
```

Логи будут записываться в `/wp-content/debug.log`
